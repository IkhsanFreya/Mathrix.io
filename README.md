## Overview

Mathrix.io transforms calculus problem-solving into an intuitive digital experience. Developed as a university research project for advanced mathematics, the platform combines interactive slides, visual proof demonstrations, and responsive calculation tools.

## Key Capabilities

- **Calculus II Visualization**: Graphical representations of definite integrals, volume of revolution, and Taylor series.
- **Interactive Slide Showcase**: Smooth swiper-driven navigation for modular learning chapters.
- **Video & Multimedia Integration**: Embedded visual guides and conceptual breakdowns.
- **Clean Architecture**: Lightweight frontend structure for seamless client-side execution.

## Technology Stack

- **Frontend**: Vanilla JavaScript (ES6+), Semantic HTML5, CSS3
- **Components**: Swiper.js for responsive touch-enabled carousels
- **Design**: Dark-mode luxury minimalist palette

## Quick Start

```bash
git clone https://github.com/IkhsanFreya/Mathrix.io.git
cd Mathrix.io
start index.html
```
